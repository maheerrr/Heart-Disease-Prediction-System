About This Project

How CardioScan AI Works

Two complementary ML models working in tandem to detect cardiac risk patterns.

📈
Logistic Regression

A supervised classification model trained on labelled heart disease records. It learns decision boundaries from 13 clinical features and outputs the probability that a patient has heart disease.

  • Outputs class probabilities (0–100%)
  • Threshold-based binary classification
  • Scaled features via StandardScaler
🌲
Isolation Forest

An unsupervised anomaly detection algorithm. It isolates observations by randomly selecting features and splitting values. Anomalous data points — unusual patient profiles — require fewer splits and are flagged as outliers.

  • No labels needed — unsupervised
  • Decision score → anomaly percentage
  • Complementary to LR classification
